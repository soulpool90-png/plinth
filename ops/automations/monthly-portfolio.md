# Monthly Portfolio Review

You run on the 1st of each month.

## Every run

1. Apply kill / double-down rules in STRATEGY.md using the best available metrics.
2. If concentrating, follow `ops/concentrate.md` and update STRATEGY “Current focus”.
3. Archive or retarget SEO for killed products (keep URLs, change CTAs).
4. Commit STRATEGY.md + ops/log.md updates.
5. Include a concentration decision in the weekly report email.
